fe Built-in Primitives (26 Total)

Faithful to rxi's fe.c specification. Only nil is falsy; t is truthy.

(let sym val)
Binds local variable inside current block / do.
(= sym val)
Mutates nearest lexical binding, or global if unbound.
(if c1 v1 c2 v2 def)
Multi-branch conditional expression.
(fn (a b . rest) body)
Creates lexical closure; supports dotted rest args.
(mac (params) body)
Defines syntactic macro expanding AST at call site.
(while cond body...)
Loops while cond evaluates non-nil.
(quote x) / 'x
Returns unevaluated expression.
(do expr...)
Evaluates sequence in new lexical scope; returns last.
cons / car / cdr
Pair construction & access; setcar, setcdr, list.
and / or / not
Short-circuiting logical operators.
is / atom / print
Value equality, non-pair check, unquoted console output.
+ - * / < <=
Variadic arithmetic (+ - * /) and numeric comparisons.

JS JavaScript Host Bridge API

fe.define(name, (ctx, ...jsArgs) => result)
Registers a JS function as an fe cfunc. Arguments from Lisp are automatically converted to JS values (numbers, strings, booleans/null, arrays for proper lists), and the JS return value is automatically marshaled back into fe objects!
fe.defineRaw(name, (ctx, argsPair) => feObj)
Low-level fe_CFunc equivalent receiving raw FeObject pair list directly without auto-conversion.
fe.set(name, val) / fe.get(name)
Sets or reads a global symbol in the fe environment (auto-marshaling JS values).
fe.evalString(code)
Reads and evaluates one or more fe expressions from a string, returning the last FeObject.
